# The One-Line Exit

A one-line resignation letter for the make.fun bounty
**The One-Line Exit** (`u-kreutzx-the-one-line-exit-1dc652d1`).

## Entry

> I resign: after four years fixing everyone's computers, I've decided to turn myself off and on again — permanently.

The entry is 115 characters, a single line. An IT support worker quits
using the one fix every IT worker prescribes — turning it off and on
again — applied to himself, permanently.

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. The program is
deterministic (the same text on every run), uses no network and has no
dependencies beyond the Python 3.13 standard library.
